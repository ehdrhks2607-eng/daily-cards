오늘 인스타에 올라간(올라갈) 영상 3개예요. 영상 저장 → 네이버 블로그 앱에서 클립 만들기 → 제목·설명·태그 붙여넣기.

업로드 순서 (1편에 1분)
  1. 아래 영상 저장을 눌러 영상을 열고, 공유 → 동영상 저장
  2. 네이버 블로그 앱 → 하단 + → 클립 만들기 → 저장한 영상 선택
  3. 제목 복사 · 설명 복사를 눌러 차례로 붙여넣기 (태그는 설명 끝에 들어 있어요)
  4. 올린 뒤 댓글 복사 → 내 클립에 첫 댓글로 달고 고정 (카톡 링크가 들어 있어요)
  5. 🥕 당근: 비즈프로필 → 스토리 올리기 → 같은 영상 선택 → 당근 문구 복사 붙여넣기 → 올린 뒤 당근 댓글 복사로 첫 댓글 달기 (당근은 외부 링크 대신 '채팅하기'로 연결 — 당근 AI가 카톡 링크를 보내요)
  6. 올리는 시간은 인스타와 비슷하게: 금전운 아침 · 연애운 점심 · 내일의 운세 밤
