# 도아도령 주문 리포트 제작 지침 (새 채팅에서 Claude가 읽는 파일)

사용자가 **카톡 주문 스크린샷** 또는 `[주문]` 양식을 보내면 이 문서대로 리포트 PDF를 만든다.
(매일 자동 게시 작업과는 별개다. 예약 작업은 이 문서를 실행하지 않는다.)

## 🔒 절대 규칙 (개인정보 · 저장소는 공개 repo)
- 손님 이름·생년월일·고민·이메일이 들어간 파일(spec.json, PDF, HTML)은 **절대 저장소에 넣거나 커밋하지 않는다.** 스크래치패드(임시 폴더)에서 만들고, 사용자에게 파일로 보낸다.
- 이메일·입금자명·전화번호는 리포트에 쓰지 않는다. 받아도 무시한다.
- `reports/LEDGER.md`에는 **이름 없이** 번호·날짜·상품·MBTI·일간만 적는다.

## 작업 순서
1. 스크린샷/양식에서 이름(닉네임), 생년월일, 양력/음력(윤달), 태어난 시간, 성별, MBTI, 고민, 상품을 읽는다. 상품이 없으면 문구로 판단한다("신청해주셔서 감사해요 (11/8까지 선착순 5분)" = **무료 팩폭(light)**).
2. 사주 계산 (추측 금지, 스크립트 출력만 쓴다):
   `python scripts/saju_pillars.py <YYYY-MM-DD> <HH:MM|모름> --gender F|M [--lunar] [--leap]`
   - 음력이면 `pip install korean-lunar-calendar` 후 `--lunar`.
   - `WARN`이 나오면 리포트는 만들되, 사용자에게 "만세력 앱으로 ○○ 한 번 확인해 주세요"라고 알린다.
   - 앞으로 몇 달의 월건은 `python scripts/saju_pillars.py <그 달 15일> 12:00 --gender F`의 **월주**로 확인한다. 참고: 2026-11 己亥 / 12 庚子 / 2027-01 辛丑 / 02 壬寅 / 03 癸卯 / 04 甲辰 / 05 乙巳 / 06 丙午 / 07 丁未 / 08 戊申 / 09 己酉 / 10 庚戌 / 11 辛亥 / 12 壬子. 2026년 = 丙午년, 2027년 = 丁未년.
3. 아래 "해석 규칙"과 "상품별 구성"대로 spec.json을 스크래치패드에 쓴다(형식: `reports/example_spec.json`).
4. `python reports/build_report.py <spec.json> <스크래치패드>/<이름>님_<상품>리포트.pdf`
   - 필요하면 `pip install playwright`(브라우저는 이미 설치됨). `WARN 넘친 페이지`가 나오면 글을 줄이거나 페이지를 나눠 다시 만든다.
   - `pdftoppm -r 40 -png`로 페이지를 이미지로 떠서 직접 보고 잘림·깨짐을 확인한다.
5. 사용자에게 PDF를 보내고 아래를 함께 준다: 사주 여덟 글자 / 리포트 요약 표 / 메일 제목·본문(복붙용) / WARN 안내.
6. `reports/LEDGER.md`에 한 줄 추가하고 커밋·푸시한다(이름 없이).

## 해석 규칙 (책 「사주 몰라도 됩니다」 + 도아도령 방식)
**원칙**
- 존댓말, 따뜻하고 차분하게. 손님 이름은 "○○님"으로 부른다.
- 희망적·건설적으로. **약점은 반드시 보완법과 함께.**
- 단정 금지: "~한 흐름으로 읽혀요", "상대적으로 ~한 기운이 강해요".
- 금지: 반드시·100%·무조건·확실히, 헤어진다·망한다, 죽음·사고·질병·수술 암시, 구체적 금액·종목·병명·소송 결과, 공포 조장.
- **결정 유도 금지**: 건강·투자·법률·이직·퇴사·이혼을 하라/말라 하지 않는다 → "믿을 만한 선배·전문가와 함께 고민해 주세요".
- 면책 문구는 빌더가 마지막 페이지에 자동으로 넣는다(지우지 않음).

**사주 × MBTI 장면형 (사용자가 정한 핵심 방식)**
- "INTP는 신금이다" 같은 **짝짓기·매핑 금지.** 대신 장면 → 이유:
  - 질문: "○○할 때 이렇지 않으세요?" (구체적인 생활 장면, 손님 고민과 연결)
  - 사주: 그 장면이 생기는 사주 구조 (오행 많고 적음, 십성, 합·충) — 한자는 괄호로 살짝만
  - MBTI: 같은 장면을 MBTI 성향으로 한 줄
  - → 팁: 오늘 바로 해볼 수 있는 작은 행동 1개
- "사주로 본 기질" 칸은 사주가 MBTI 4축 중 어디와 비슷한지만 가볍게(예: "I·S·F / P만 반반"). 페이지 하단에 MBTI 해석 틀 안내(`"note": true`).
- 손님이 적은 **고민은 반드시 한 페이지 이상 직접 다룬다**(장면 카드 + Q&A).

**PART 구성 규칙 (⭐·👑 — 사주와 MBTI를 따로 본 뒤 연결)**
- PART 제목은 페이지 제목 앞에 붙인다: `"title": "PART 1 · 사주팔자"`.
- **PART 1 사주**: MBTI 얘기 없이 사주만. 여덟 글자·오행·성격을 쉬운 말로.
- **PART 2 MBTI**: 사주 얘기 없이 MBTI만. 손님 유형의 4축(E/I·S/N·T/F·J/P) 각각 한 줄, 강점 3, 지칠 때 신호 3, 회복법. 일반적으로 알려진 성향 설명으로 쓰고 "공식 검사 해석이 아니에요"를 한 줄 넣는다.
- **PART 3 연결 — 첫 페이지 "두 렌즈로 함께 보면"** (필수, 아래 설명을 손님에 맞게 다듬어 넣는다):
  - "사주는 태어난 순간의 **타고난 설계도**, MBTI는 지금 내가 느끼는 **현재의 사용 설명서**예요. 둘은 뿌리가 다른 도구라 억지로 짝짓지 않고, 같은 장면을 두 렌즈로 함께 비춰 봐요."
  - "두 렌즈가 **같은 말을 하는 부분**은 타고난 기질을 그대로 쓰고 있는 강점이에요. **다른 말을 하는 부분**은 환경·역할 때문에 스스로 조정해 온 부분일 수 있어요. 어느 쪽이 더 편한지가 나를 덜 지치게 쓰는 힌트예요."
  - 표: 4축마다 `축 | 사주에서 보이는 기질(근거) | MBTI | 같음/다름 | 한 줄 해석`.
  - 그다음 페이지부터 🔥 팩폭 장면 카드(위 장면형 규칙). 팩폭은 아프게가 아니라 "들켰다" 느낌으로, 매 카드 끝은 팁.

**쉬운 말 사전**
- 오행: 나무=성장·돈(일간에 따라 다름), 불=표현·온기·추진력, 흙=안정·버팀, 쇠=결단·기술, 물=생각·지혜.
- 십성(일간 기준): 비견·겁재=나와 같은 기운(자존심·경쟁·나눠 갖기) / 식신=손재주·꾸준한 표현 / 상관=말·표현·틀 깨기 / 정재=꾸준한 돈·손님 / 편재=움직이는 돈·기회 / 정관=책임·평가·규칙 / 편관=압박·추진·긴장 / 정인=배움·지지 / 편인=직감·혼자만의 생각.
- 관계: 육합=손잡음, 삼합·반합=힘이 모임(빠진 글자가 들어오는 해·달에 완성), 충=부딪힘(변화), 형=마찰·재정비, 육해=작은 오해, 천간합=마음이 묶임.
- 일지 = 배우자·생활 자리. 월주 = 사회·일. 시주 = 미래·결과물.
- 지장간에 숨은 기운 = "숨어 있는 재능/기운" (겉으로 안 보이지만 있음).

## 기간별·연도별 흐름 계산 (⭐·👑 필수)
`python reports/flow_table.py --day <일주> --natal <년,월,일,시> --months 2027 --calendar` → **양력 2027년 1월~12월** 12달(1월은 사주상 전년 丑월이라 `--calendar`를 꼭 붙인다) 각각의 절입 날짜, 월건, 그 달 안의 **사령 기간(예: 2/4~2/10 戊 정인 / 2/11~2/17 丙 정관 / 2/18~3/5 甲 정재)**, 원국과의 합·충, 초안 문장.
`python reports/flow_table.py --day <일주> --natal <...> --years 2027 10` → 10년 세운: 그해 간지·십성·원국과의 관계·**힘 받는 달 2개 / 쉬어갈 달 2개**.
- 날짜·간지·십성·달 고르기는 스크립트 출력만 쓴다. `draft`는 뼈대라서, 손님의 사주 구조·MBTI·고민에 맞게 문장을 다시 쓴다(같은 팁 반복 금지).
- 월별 한눈에 표와 기간별 표 모두 **1월부터 12월까지** 넣는다(사주 해는 입춘에 바뀌므로 1월은 "병오년 마지막 달"이라고 한 줄 설명).
- 기간별 표: 3개월씩 한 페이지. 달 머리줄 = `○월 ○일 ~ ○월 ○일 · 간지월 · [태그] 한 줄 요약`, 그 아래 사령 기간마다 `기간 | 기운(천간 + 십성) | 이렇게 해 보세요`. 손님에게 좋은 달 머리줄은 노란색 강조.
- 연도별(👑, PART 6 — 월별·기간별 **뒤**): 한눈에 표 1쪽 + **상세 5쪽(한 쪽에 2년)**. 해마다 ① 머리 박스: 연도·세운·대운, 천간/지지 십성 뜻, 원국과의 합·충 ② 힘 받는 달 2 · 쉬어갈 달 2 표: `달(간지·날짜) | 왜 그런가요(천간 십성, 지지 십성, 합·충 — flow_table의 best_detail/care_detail.why) | 이렇게 해 보세요`. 근거를 손님 말로 풀고, 힘 받는 달의 약점은 "다만", 쉬어갈 달의 장점은 "그래도"로 함께 적는다.
- 연도별 한눈에 표(👑): `연도 | 세운(+대운) | 그해의 기운(+일지 관계 한 줄) | 힘 받는 달 | 쉬어갈 달` + "10년 흐름 한 줄" 박스(일지와 합이 드는 해 등 기준점 1~2개).
- 쉬어갈 달은 "조심"이 아니라 "한 박자 쉬어가기·재확인"으로 쓴다.
